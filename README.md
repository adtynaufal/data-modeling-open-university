# 📊 Analisis Data Penjualan Ritel & Dashboard Interaktif

## 📝 Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis performa penjualan ritel harian, identifikasi produk terlaris, serta pola pembelian pelanggan menggunakan dataset transaksi ritel.

## 🛠️ Tools & Metodologi
- **Database & Query:** SQL (Oracle / MySQL)
- **Data Preparation:** Power Query & Excel
- **Data Visualization:** Tableau Public
- **Methodology:** Star Schema & Data Warehousing Design

## 📁 Struktur File dalam Repository
- `dataset/`: Dataset sampel transaksi ritel (`.csv`).
- `queries/`: Skrip SQL untuk pembersihan dan agregasi data (`.sql`).
- `docs/`: Dokumentasi skema basis data dan diagram (`.pdf`).
